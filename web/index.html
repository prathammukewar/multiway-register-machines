    How to read this

    Each chip is one configuration of the machine, written as the program counter and then the register values. An arrow is one rule firing, and its color and label say which rule. The rows are steps: everything in a row was first reached at that step, so the play button and the slider show the evolution unfolding in time.

    Hover a chip or an arrow for details. Click a chip to see where it came from and where it leads. Drag to pan, scroll to zoom, or use the zoom buttons. If the graph is hard to see, the table view lists the same states as text, and every figure can be exported.

    • space play or pause
    • ← → one step back or forward
    • + − 0 zoom in, out, fit (graph focused)
    • esc clear the selection

    Large graph: drawn on a canvas without labels. Graphs under 2000 nodes get the interactive view.
